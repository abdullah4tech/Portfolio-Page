Zenon Router is a fast, minimal HTTP router for Node.js built with a focus on performance and developer experience. Zero external dependencies, fully tree-shakeable, and designed for maximum throughput on high-concurrency workloads. A drop-in alternative to heavier routing libraries.

## Highlights

- Zero external dependencies — just the Node.js stdlib
- Trie-based route matching for O(k) lookup time
- Middleware chaining with full async/await support
- TypeScript-first with complete type inference
- Benchmarked faster than Express on common workloads
