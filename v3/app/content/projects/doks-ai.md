Doks AI is an intelligent document query engine powered by a Retrieval-Augmented Generation (RAG) pipeline. Upload any document — PDFs, Markdown, plain text — and get precise, cited answers to your questions instantly. Built for developers and teams who need fast, reliable insight from their documentation without manually reading through it.

## Highlights

- RAG pipeline with semantic chunking and vector embeddings
- Supports PDF, Markdown, and plain text documents
- Cited answers with source paragraph references
- Fast retrieval with pgvector integration
- REST API for embedding into existing documentation tools
