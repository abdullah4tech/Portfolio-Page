fsh is a modern, fast shell for the terminal designed to replace the daily-driver shell for developers. It features intelligent context-aware autocomplete, a lean plugin ecosystem, and a blazing-fast startup time — making every terminal session noticeably more productive without sacrificing compatibility.

## Highlights

- Sub-50ms startup time
- Context-aware intelligent autocomplete
- Plugin API for custom commands and integrations
- Built-in git status and branch display in the prompt
- Compatible with existing bash/zsh configs
